# /wrapup — 言行不一致チェッカー

セッション中の「やる」という宣言と、実際のコード変更を突合して、
やり残しを 3 分類で報告するスキル。最後にまとめを comP のセッション
メモリに記録し、次回セッションの `session_recall` で拾えるようにする。

## 手順

### 1. 会話履歴を取得する

`mcp__comp__session_recall` を `{"limit": 30}` で呼ぶ。

- 履歴が空（初回セッション等）の場合はエラーにせず
  「セッション履歴がありません」と報告して、手順 3 の git 確認だけ行う。

### 2. 履歴から「実行の約束」を抽出する

以下のような宣言を約束として拾う:

- 「〜する」「〜しておく」「後で〜」「次に〜」
- 「TODO」「テスト書く」「直す」「追加する」「更新する」
- ユーザー発言・アシスタント発言の**両方**を対象にする
  （「やっておきます」も約束）

### 3. 実際のコード変更を取得する

1. まず `mcp__comp__get_git_diff_context` を呼ぶ。
2. 取れない・空の場合は Bash で代替する:
   - `git status --porcelain`
   - `git log --oneline -10 --stat`

### 4. 約束と変更を突合し、3 分類で報告する

- ✅ **完了**: 約束に対応する変更が確認できた（対応 commit / ファイルを添える）
- ❌ **未着手**: 約束したが対応する変更が見当たらない
- ⚠️ **判定不能**: 対応関係が曖昧。**正直に「不明」と言う。無理にどちらかに
  寄せない。捏造しない。**

git 変更がゼロの場合は「変更なし」と報告し、約束だけがあれば全部 ❌ になる。

### 5. まとめを記録する

`mcp__comp__session_log` で本日のまとめ（完了 / 未完了リスト）を記録する。
`request` には「/wrapup: セッションまとめ」、`outcome` には分類結果を書く。

## 出力フォーマット

```text
📋 今日の宣言 vs 実績
✅ Token validation にキャッシュ追加 → packages/magatama-core/... で確認
❌ 「エッジケースのテスト書く」→ tests/ に変更なし
⚠️ 「ドキュメント更新」→ README.md に変更はあるが該当箇所か不明
💾 このまとめを session_log に記録しました。
```
